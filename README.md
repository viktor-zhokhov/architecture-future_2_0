# architecture-future_2_0

Проектная работа 11 спринта курса «Архитектор ПО» (Яндекс Практикум) — кейс компании «Будущее 2.0» (медицинский стартап, выросший в холдинг с банковской лицензией и ИИ-сервисами).

## Структура

- **Task1** — целевая архитектура (C4 Container) на горизонте года, анализ проблемных мест и их приоритизация (MoSCoW).
- **Task2** — разделение системы на домены (Клиника, Финтех, ИИ-сервисы, Партнёры) и DFD потоков данных между ними.
- **Task3** — технический радар и роадмап технологических изменений с обоснованием по этапам.
- **Task4** — диаграмма автоматизации развёртывания и рабочая Terraform-конфигурация (Yandex Cloud).

Решение оформлено в виде пул-реквеста `solution` → `main`.
